# v1.0 设置面板说明

## 目标

v1.0.6 开始为主面板减负，把低频配置从主面板 tab 中收纳到角色旁三点菜单入口。

主面板保留高频功能：

* 专注
* 陪伴
* 问问

设置入口：

```text
角色旁三点菜单 → 设置
```

## 设置面板内容

当前设置面板包含：

* AI 配置：AI 陪伴开关、Provider、Base URL、API Key、Model、DeepSeek 推荐配置和保存/清空。
* 窗口与启动：开机启动状态与切换入口。
* 低频主动陪伴：主动陪伴开关与本地规则说明。
* 本地数据与隐私：API Key、本地记忆、AI 日记和无云同步说明。
* 关于：Focus Pet 的本地优先定位。

## 行为边界

本次只调整入口和展示：

* 不改 `aiSettings` 结构。
* 不改 API Key 保存方式。
* 不改问问霍霍请求逻辑。
* 不改 AI 日记生成逻辑。
* 不改 AI 日记保存逻辑。
* 不改 `dailyDiaries`、`companionMemory` 或 `temporaryChatTurns` 结构。
* 不改开机启动、托盘、通知或窗口透明穿透逻辑。
* 不新增 BrowserWindow。
* 不新增依赖。

## 主面板变化

主面板导航简化为：

* 专注
* 陪伴
* 问问

“去设置”入口会打开设置面板，不再跳转到主面板中的设置 tab。

## 隐私说明

设置面板集中说明：

* API Key 只保存在本机 `localStorage`。
* 问问霍霍只发送必要的轻量上下文。
* AI 日记只发送今日小结摘要。
* 保存的日记只保存在本地。
* 当前没有登录、后端或云同步。
