# v1.0 AI 日记封存前检查

## 结论

v1.0 AI 日记闭环已形成：

```text
本地今日小结 → 手动生成 AI 日记 → 手动保存 → 最近 3 篇回顾
```

本次检查不新增功能，只确认链路边界和稳定性。

## 今日小结

已确认：

* `src/services/dailySummary.ts` 中的 `buildLocalDailySummary(input)` 是纯函数。
* 不读取 `localStorage`。
* 不写入 `localStorage`。
* 不依赖 React。
* 不调用 AI。
* 输入异常时安全 fallback。
* 汇总今日专注轮数、专注分钟、小任务数量、霍霍能量和最多 3 个状态标签。
* 今日无数据时使用温和文案。

## AI 日记生成

已确认：

* 只有点击“让霍霍写成日记”才调用 `generateAiDiary`。
* 不在启动、打开 tab、小结变化或保存日记时自动请求。
* 请求只发送今日小结 `summaryTitle / summaryLines / summaryFooter`。
* 不发送完整专注记录、小任务列表、`companionMemory`、`dailyDiaries` 或 `temporaryChatTurns`。
* 不写 `localStorage`、`companionMemory.notes` 或 `temporaryChatTurns`。
* 生成中支持取消。
* 取消、失败和空结果不会显示保存入口。

## 手动保存

已确认：

* 只有 AI 日记生成成功后才显示“保存这篇日记”。
* 用户点击后才写入 `focusPet.dailyDiaries`。
* 保存成功后显示“已保存”。
* 同一篇当前结果不能重复保存。
* 新生成日记后保存状态会重置。
* 保存内容仅包含 `id / date / source / title / text / summarySnapshot / createdAt`。
* 不保存 API Key、完整请求 payload、完整任务列表、完整专注记录、完整 `companionMemory` 或 `temporaryChatTurns`。

## dailyDiaries Storage

已确认：

* localStorage key 为 `focusPet.dailyDiaries`。
* `version` 为 `1`。
* 默认状态为空数组。
* 读取失败和 JSON parse 异常会安全 fallback。
* 无效 diary 会被过滤。
* 文本会 trim，空文本不保存。
* 单篇文本限制在 1000 字以内。
* 最多保留 100 篇。
* `date` 使用本地 `YYYY-MM-DD`。
* `getRecentDailyDiaries(limit = 3)` 按 `createdAt` 倒序。
* `deleteDailyDiary(id)` 只删除对应 id，不存在时安全返回。

## 最近保存日记列表

已确认：

* “陪伴”tab 中存在“最近保存的日记”区域。
* 无日记时显示友好空状态。
* 保存成功后列表立即刷新。
* 只显示最近 3 篇。
* 每篇显示日期、标题和摘要。
* 支持展开 / 收起查看全文。
* 同时只展开一篇。
* 删除单篇后列表立即刷新。
* 删除展开中的日记会清空展开状态。
* 删除日记不影响当前 AI 日记结果。

## 隔离边界

已确认 AI 日记链路不影响：

* “问问霍霍”请求、loading、error、cancel 状态。
* 临时 3 轮上下文 `temporaryChatTurns`。
* “记住这次”。
* “霍霍建议记住”。
* `companionMemory.notes`。
* 状态标签、陪伴小记、主动陪伴。
* 今日小任务、霍霍能量、今日专注记录、每日目标和休息流程。
* Live2D、视线回正、透明穿透、动态高度、托盘、通知和开机启动。

## 当前不做

* 不做完整历史页。
* 不做时间轴。
* 不做搜索。
* 不做筛选。
* 不做导出。
* 不做分享。
* 不做日历视图。
* 不做周报或月报。
* 不做图表。
* 不做云同步。
* 不新增第五个 tab。
