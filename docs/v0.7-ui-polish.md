# v0.7.3 面板视觉优化说明

## 目标

让完整面板更像柔和的桌宠陪伴面板，而不是后台配置页。

## 本次范围

* 只优化视觉层级、间距、材质和轻量过渡。
* 不新增功能。
* 不改 AI 请求逻辑。
* 不改临时上下文逻辑。
* 不改本地记忆结构。
* 不改专注流程。

## 视觉原则

* 专注操作、今日记录、陪伴小记、问问霍霍和 AI 设置分层更清晰。
* AI 设置保持低优先级，不抢主视觉。
* 面板展开、AI 回复、记忆建议和按钮状态使用轻量淡入过渡。
* 保持低干扰桌宠体验，不做聊天 App 化。

## v0.7.4 面板分区切换

v0.7.4 将完整面板从单个长滚动区域调整为“专注 / 陪伴 / 问问 / 设置”四个轻量分区，默认停留在“专注”分区，避免日常开始专注时被记忆、AI 和配置内容干扰。

四个分区职责如下：

* 专注：目标输入、时长选择、开始按钮、今日简短进度和最近记录。
* 陪伴：陪伴小记、本地状态标签、本地小回顾、查看与清空本地记忆。
* 问问：一次性 AI 回复、取消请求、最近回复、记住这次、临时 3 轮上下文提示和清空入口。
* 设置：AI 陪伴开关、Provider / Base URL / API Key / Model、DeepSeek 推荐配置和本地隐私说明。

本次只调整信息架构和展示方式，不新增功能，不改变 AI 请求、记忆保存、临时上下文、专注状态机、Live2D 或窗口系统逻辑。

### v0.7.4 hotfix

* 每个 tab 使用独立内容滚动区，内容较多时只在当前分区内滚动。
* 完整面板不回退为所有功能同屏的长滚动页。
* 内容区底部增加安全留白，避免圆角面板裁切“记住这次”“清空临时对话”等底部按钮。
* 只修复布局裁切与滚动体验，不改变 AI、记忆、专注或窗口系统逻辑。

## v0.7.5 面板精修二次打磨

v0.7.5 继续围绕完整面板的陪伴感做视觉细节打磨，不新增功能，也不改变任何业务逻辑。

本次精修包括：

* 顶部标题区精修，让状态、标题和今日统计更协调。
* tab 分段按钮视觉优化，让当前分区高亮更柔和。
* tab 内容切换增加轻量淡入和位移过渡。
* 问问 tab 操作区整理，让输入、发送、记住这次和临时上下文提示更稳定。
* 陪伴 tab 统一卡片间距、状态标签和本地小回顾的视觉层级。
* 设置 tab 继续低频化展示，让 AI 配置更像轻量设置卡片而不是表单堆叠。

边界保持不变：不改 AI 请求逻辑、不改临时上下文、不改记忆保存、不改专注流程、不改 Live2D 和窗口系统能力。

## v0.7.6 真实使用路径微调

v0.7.6 围绕真实使用路径做轻量文案、引导和空状态微调，让用户更容易从默认状态开始专注，也更清楚何时需要去设置 AI。

本次调整包括：

* 默认专注入口优先，目标输入和开始按钮的引导更直接。
* 今日记录为空时，使用更温和的“先来一轮 5 分钟热身”提示。
* 陪伴 tab 空状态更自然，提示完成专注或在问问中选择记住内容后会出现小记。
* 问问 tab 在 AI 未开启或配置不完整时，显示“去设置”引导；该按钮只切换 tab，不触发 AI 请求。
* 设置 tab 简化配置说明，强调 DeepSeek 推荐配置、API Key 本地保存和发送时才请求配置的 AI 服务。

本次仅做文案、引导和轻量视觉微调，不改 AI 请求、临时上下文、记忆保存、专注流程、Live2D 或窗口系统逻辑。

## v0.7.7 封存前检查

v0.7.7 作为 v0.7 阶段封存前检查节点，只整理回归清单和文档记录，不新增功能，不主动调整 UI，也不改变业务逻辑。

检查清单见 `docs/v0.7-release-checklist.md`，覆盖四分区面板、专注流程、AI 配置与问问路径、临时上下文、本地记忆、陪伴分区、Live2D、窗口能力和打包验证。
