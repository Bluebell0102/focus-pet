# v1.0 流畅度优化说明

v1.0.7 主要处理主面板、设置面板、倒计时、窗口 resize 和透明穿透检测带来的卡顿风险。

## 优化范围

* React 派生数据使用 `useMemo`，减少倒计时秒跳时的重复计算。
* 陪伴记忆、状态标签、小任务统计、今日小结等重内容不跟随倒计时重复派生。
* 紧凑窗口高度适配从倒计时文本变化中解耦，只跟随主要布局状态变化。
* 鼠标穿透检测使用 `requestAnimationFrame` 合并，避免每次 `mousemove` 都立即执行 DOM 查询。
* Electron 主进程对窗口 resize 和 `setIgnoreMouseEvents` 做去重。
* Live2D 组件使用 `React.memo`，避免与普通面板状态过度耦合。
* CSS 降低大面积毛玻璃、阴影和进入动画成本。

## 非目标范围

* 不改变专注流程。
* 不改变 AI 请求逻辑。
* 不改变 AI 日记生成或保存逻辑。
* 不改变小任务、霍霍能量、陪伴记忆和日记的数据结构。
* 不新增依赖。
* 不修改 `package.json` version。
