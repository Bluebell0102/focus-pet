# v0.6.0-dev 手动验收清单

## AI 记忆

* AI 回复后可点击“记住这次”。
* 不点击不会保存。
* 建议记住只在偏好 / 习惯类输入中出现。
* 点击“不用”不会保存。
* 清空陪伴记忆能清除保存内容。

## Live2D 生命感

* idle 不长时间完全静止。
* focusing 不过度干扰。
* resting 有轻微放松感。
* 鼠标离开后视线回正。
* 快速移入移出不会卡视线。

## 主流程

* 快速开始。
* 3 秒准备。
* 专注。
* 完成反馈。
* 休息。
* 再来一轮。

## 系统能力

* 透明穿透。
* 动态高度。
* 隐藏控制入口。
* 拖动。
* 托盘。
* 通知。
* 开机启动。
* 记住窗口位置。
