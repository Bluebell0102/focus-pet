# v1.0 本地每日小结说明

## 为什么做

v1.0 开始探索“每日小结 / AI 日记”方向。v1.0.1 先完成本地规则生成的小结，用于把当天的专注、任务、能量和状态轻量汇总在一起。

这不是完整 AI 日记，也不是历史日记系统。

## 当前数据来源

今日小结只读取当前已经存在的本地状态：

* 今日专注轮数。
* 今日累计专注分钟数。
* 今日完成小任务数量。
* 今日霍霍能量。
* 最近状态标签，最多 3 个。
* 今日目标是否达成。

## 本地规则生成

生成逻辑位于：

```text
src/services/dailySummary.ts
```

`buildLocalDailySummary(input)` 是纯函数：

* 不读取 localStorage。
* 不写入 localStorage。
* 不依赖 React。
* 不调用 AI。
* 不新增网络请求。
* 输入异常时安全 fallback。

## 展示位置

今日小结显示在“陪伴”tab 中，靠近本地小回顾和霍霍能量卡片。

当前展示内容包括：

* 标题。
* 2-4 行简短总结。
* 一句温和结尾。

## 隐私边界

v1.0.1：

* 不调用 AI。
* 不读取 API Key。
* 不请求 DeepSeek 或其他网络服务。
* 不写入 `temporaryChatTurns`。
* 不写入 `companionMemory.notes`。
* 不保存每日小结历史。
* 不自动生成日记列表。

## v1.0.2 一键生成 AI 日记

v1.0.2 在“陪伴”tab 的今日小结下增加“让霍霍写成日记”入口。

该能力只会在用户手动点击后触发，不会自动生成、不会后台请求，也不会切换 tab 或弹窗。

发送给 AI 的内容只包含：

* 今日小结标题。
* 今日小结行内容。
* 今日小结结尾。

当前不会发送完整今日记录、小任务列表、陪伴记忆、`temporaryChatTurns` 或聊天历史。

生成结果只保存在当前 React state 中：

* 不写入 `localStorage`。
* 不写入 `companionMemory.notes`。
* 不写入 `temporaryChatTurns`。
* 不触发“记住这次”。
* 不触发“霍霍建议记住”。
* 与“问问霍霍”的临时上下文和请求状态隔离。

## v1.0.3 手动保存 AI 日记

v1.0.3 在 AI 日记生成成功后增加“保存这篇日记”入口。

保存规则：

* 必须用户手动点击后才保存。
* 生成中、取消、失败或空文本不会保存。
* 同一天相同文本不会重复保存。
* 重新生成新日记后，保存状态会重置。

保存位置：

```text
localStorage: focusPet.dailyDiaries
```

保存内容只包含：

* `date`
* `source: 'ai'`
* `title`
* `text`
* `summarySnapshot`
* `createdAt`

边界：

* 不保存 API Key。
* 不保存完整任务列表。
* 不保存完整今日专注记录。
* 不保存完整 `companionMemory`。
* 不写入 `companionMemory.notes`。
* 不进入 `temporaryChatTurns`。
* 不触发“记住这次”。
* 不触发“霍霍建议记住”。
* 不做历史列表、时间轴、导出或云同步。

## v1.0.4 日记列表 / 历史回顾雏形

v1.0.4 在“陪伴”tab 增加“最近保存的日记”区域。

当前能力：

* 只展示最近 3 篇已保存 AI 日记。
* 按 `createdAt` 倒序显示。
* 每篇显示日期、标题和正文摘要。
* 支持展开 / 收起查看全文。
* 支持删除单篇日记。
* 删除后列表立即刷新。

边界：

* 不展示未保存的当前 AI 日记。
* 不自动保存当前 AI 日记。
* 不做时间轴。
* 不做搜索。
* 不做导出。
* 不做云同步。
* 不新增第五个 tab。
* 与 `companionMemory` 隔离，不写入 `companionMemory.notes`。
* 不进入 `temporaryChatTurns`。
* 不调用 AI，不新增网络请求。

## v1.0.5 AI 日记封存前检查

v1.0.5 只做封存前检查与文档整理，不新增功能。

检查范围：

* 今日小结检查：确认 `buildLocalDailySummary(input)` 是纯函数，不读写 `localStorage`，不调用 AI，不依赖 React，输入异常时安全 fallback。
* AI 日记生成检查：确认只有用户点击“让霍霍写成日记”才请求 AI，且只发送今日小结 `title / lines / footer`。
* 手动保存检查：确认只有生成成功后才显示保存入口，取消、失败、空文本和生成中状态不能保存。
* `dailyDiaries` storage 检查：确认 key 为 `focusPet.dailyDiaries`，默认空数组，读取异常安全 fallback，最多保留 100 篇，同日同文本去重。
* 最近保存日记列表检查：确认只展示最近 3 篇，按 `createdAt` 倒序，支持展开 / 收起和删除单篇。
* 隔离检查：确认 AI 日记链路不写 `companionMemory.notes`，不进入 `temporaryChatTurns`，不触发“记住这次”或“霍霍建议记住”。

非目标范围：

* 不做时间轴。
* 不做搜索。
* 不做导出。
* 不做云同步。
* 不做完整历史系统。
* 不新增第五个 tab。

详细检查清单见：

```text
docs/v1.0-ai-diary-checklist.md
```

## v1.0.6 设置入口调整

AI 日记和问问霍霍的配置入口已收纳到角色旁三点菜单中的“设置”面板。

主面板仍保留高频区：

* 专注。
* 陪伴。
* 问问。

当 AI 未开启或配置不完整时，“去设置”会打开设置面板，而不是跳转到旧设置 tab。

* 不做图表。
