# v0.9 本地微任务说明

## 为什么做

v0.9 开始补齐效率助手与自我管理的基础能力。第一版只做“今日小任务”，用于把很小的待办放到专注入口附近，帮助用户更容易开始一轮专注。

## 与专注目标的关系

* 小任务可以手动设为本轮专注目标。
* 设为目标只会填入目标输入框。
* 设为目标不会自动开始专注。
* 设为目标不会自动完成任务。
* 从小任务设为目标并自然完成专注后，会询问是否完成该小任务。
* 只有用户点击“完成了”才会标记任务完成。

## 数据结构

本地存储 key：

```text
focusPet.microTasks
focusPet.growthEnergy
```

数据只包含轻量任务列表：

```ts
type MicroTask = {
  id: string
  text: string
  status: 'active' | 'completed'
  createdAt: string
  completedAt?: string
}
```

`growthEnergy` 只保存轻量事件：

```ts
type GrowthEnergyEvent = {
  id: string
  source: 'focus' | 'micro-task'
  amount: number
  createdAt: string
  refId?: string
}
```

## 本地保存边界

* 只保存在 `localStorage`。
* 不登录。
* 不上传。
* 不云同步。
* 不写入 `companionMemory.notes`。
* 不写入 AI 临时上下文。
* 不随 AI 请求发送完整任务列表。
* 霍霍能量也只保存在本地，不上传，不进入 AI 请求上下文。

## 当前不做

* 不做完整 Todo App。
* 不做截止日期。
* 不做优先级。
* 不做标签。
* 不做子任务。
* 不做项目分组。
* 不做日历同步。
* 不做重复任务。
* 不做任务提醒或通知。
* 不做 AI 自动拆解任务。

## v0.9.2 小任务与专注完成轻联动

v0.9.2 增加了小任务和自然专注完成之间的轻量确认。

* `linkedFocusTaskId` 表示当前目标输入框来自哪个小任务。
* `activeFocusTaskId` 表示本轮已经开始或刚完成的专注关联哪个小任务。
* 用户手动编辑目标输入框后，会取消 `linkedFocusTaskId`，避免普通目标被误当成任务。
* 自然完成专注后，如果 `activeFocusTaskId` 仍对应一个 active 小任务，会显示“这项小任务完成了吗？”。
* 点击“完成了”才会调用 `completeMicroTask` 标记任务完成并写入 `completedAt`。
* 点击“还没”会保留任务 active，不改今日专注记录。
* 准备阶段取消、专注提前结束、主动陪伴“开始 5 分钟”都不会触发任务完成询问。
* 如果关联任务在专注过程中被删除或手动完成，完成后不会重复询问。
* 该联动不写入 `companionMemory.notes`，不写入 `temporaryChatTurns`，也不触发 AI 请求。

## v0.9.3 霍霍能量基础

v0.9.3 增加了最小本地成长值预留，当前只显示“今日霍霍能量”。

* 自然完成一轮专注会新增 1 条 `source: 'focus'` 的能量事件。
* 完成一个小任务会新增 1 条 `source: 'micro-task'` 的能量事件。
* 小任务通过专注完成确认卡片点击“完成了”时，也会按小任务完成增加 1 点能量。
* 准备取消、提前结束、休息结束、添加任务、删除任务、设为目标和点击“还没”都不会增加能量。
* `refId` 用于防重复：专注使用 focus record id，小任务使用 microTask id。
* 同一个 `source + refId` 已存在时，不会重复增加能量。
* 今日能量通过当天 `createdAt` 的事件求和得到。
* 当前不做等级、好感度、经验条、成就、徽章、商城或连续打卡。
* 能量事件不写入 `companionMemory.notes`，不写入 `temporaryChatTurns`，也不触发 AI 请求。

## v0.9.4 成长值封存前检查

v0.9.4 只做霍霍能量封存前检查和必要 hotfix，不进入完整养成系统。

* 检查 focus / micro-task energy 都使用 `source + refId` 防重复。
* 检查自然完成专注只在写入 focus record 时增加 1 点能量。
* 检查准备取消、提前结束、休息结束和“再来一轮”本身不会增加能量。
* 检查小任务添加、删除、设为目标和点击“还没”不会增加能量。
* 检查今日能量只统计本地今天 `createdAt` 的事件。
* 检查 localStorage 读取失败、JSON 异常和无效事件都能安全 fallback。
* 检查能量事件读取时 `amount` 统一归一为 1，避免旧数据或异常数据影响今日统计。
* 检查能量与 AI、陪伴记忆、主动陪伴、通知和窗口系统保持隔离。
* 详细清单见 `docs/v0.9-growth-energy-checklist.md`。
