# v0.5.2 AI 回复手动测试清单

## 正常场景

* 打开完整面板，进入 AI 设置。
* 点击“使用 DeepSeek 推荐配置”。
* 确认 Provider 为 `openai-compatible`。
* 确认 Base URL 为 `https://api.deepseek.com`。
* 确认 Model 为 `deepseek-v4-flash`。
* 填入 API Key，开启 AI 对话，并保存配置。
* 在“问问霍霍”输入“今天有点累，还要继续专注吗？”。
* 点击“发送”。
* 应显示一句简短、温柔、霍霍风格的回复。

## 配置缺失

* 未开启 AI 对话时点击发送，应提示未开启，且不请求。
* 未填写 API Key 时点击发送，应提示配置未填完整，且不请求。
* 未填写 Model 时点击发送，应提示配置未填完整，且不请求。
* Base URL 为空时点击发送，应提示配置未填完整，且不请求。
* Provider 不是 `openai-compatible` 时点击发送，应提示配置未准备好，且不请求。
* 输入为空时点击发送，应提示先写一句想说的话，且不请求。

## 错误场景

* 输入为空时点击发送，应提示先写一句想说的话，且不请求。
* 未开启 AI 对话时点击发送，应提示配置未准备好，且不请求。
* 未填写 API Key 时点击发送，应提示配置未准备好，且不请求。
* 使用错误 API Key，应显示“API Key 可能不太对。”
* 使用错误模型名，应显示“模型或地址可能没填对。”
* 使用错误 Base URL，应显示地址、模型或连接失败相关的温和提示。
* 断网后点击发送，应显示请求失败或联系不上提示。
* 请求超时，应显示稍后再试提示。
* 请求过快或额度受限，应显示请求太频繁提示。

## 边界

* 专注中不自动请求。
* 准备中不自动请求。
* 状态标签选择后不自动请求。
* 专注完成后不自动请求。
* 休息开始或结束后不自动请求。
* 不保存聊天历史。
* 不显示消息流。
* 不自动连续追问。
* 不发送完整 `companionMemory`。
* 不发送完整 notes。
* 不发送完整今日记录。

## 手动记忆

* AI 成功回复后，应显示“记住这次”。
* 用户不点击“记住这次”时，不应保存 AI 对话。
* 点击“记住这次”后，应在陪伴小记最近记忆中看到这条 note。
* 同一次回复不能重复保存。
* 新一次成功回复后，可以再次保存。
* 清空陪伴记忆后，这条 note 应一起被清除。
