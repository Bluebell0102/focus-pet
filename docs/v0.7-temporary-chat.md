# v0.7 临时对话上下文说明

## 为什么做

“问问霍霍”原本只处理单次输入。v0.7 增加轻量临时上下文，让霍霍能理解“刚才那个”“那我怎么办”这类追问。

## 当前规则

* 只带最近 3 轮对话。
* 只存在当前 React state 中。
* 不写入 `localStorage`。
* 不写入 `companionMemory`。
* 关闭应用或刷新后消失。
* 请求失败不会追加临时上下文。
* 用户可以手动清空临时对话。

## 和本地陪伴记忆的区别

临时对话上下文只是当前会话里的短期上下文，不是长期记忆。

`companionMemory` 是本地陪伴记忆，只在用户主动点击“记住这次”或确认“记住”建议后写入。

## v0.7.2 请求稳定性

* 只有成功回复才会进入临时上下文。
* 取消、失败、超时都不会进入临时上下文。
* 取消不会保存到 `companionMemory`。
* 请求中禁止重复提交。
* 请求中可以手动取消本次回复。
* 普通失败和超时会保留输入内容，方便重试。

## 保持边界

* 不做完整聊天窗口。
* 不做消息流。
* 不显示完整聊天历史列表。
* 不保存聊天历史。
* 不做后台请求。
* 专注中仍不显示 AI 对话框。
