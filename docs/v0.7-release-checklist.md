# v0.7 封存前检查清单

## 检查范围

v0.7 阶段重点是“问问霍霍”的临时上下文、请求稳定性、分区面板和真实使用路径微调。本清单用于封存前人工回归，不新增功能。

## 四个分区

* 默认打开完整面板时停留在“专注”分区。
* “专注 / 陪伴 / 问问 / 设置”四个 tab 都能正常切换。
* 切换 tab 不触发 AI 请求。
* 切换 tab 不清空目标输入、AI 输入、AI 回复或临时上下文。
* 每个 tab 都能滚动到底，底部按钮不被裁切。

## 专注流程

* idle 状态可以快速开始。
* 完整面板中可以输入本轮目标。
* 可以选择 5 / 10 / 25 分钟。
* 点击开始后进入 3 秒准备。
* 准备中可以取消，且不写入今日记录。
* 准备结束后进入正式专注，正式时长不被 3 秒扣减。
* 专注中点击角色或气泡会显示防分心提醒。
* 提前结束需要二次确认，且不写入今日记录。
* 自然完成后写入今日记录，并显示完成反馈。
* 完成后可以进入 5 分钟休息。
* 休息结束后“再来一轮 / 换个时长 / 稍后”正常。

## AI 配置路径

* 设置 tab 中 AI 陪伴开关显示正常。
* DeepSeek 推荐配置按钮正常填入 Base URL 和 Model。
* Base URL、Model、API Key 输入正常。
* 保存配置正常。
* 清空配置正常。
* 隐私说明显示完整。
* 设置 tab 可以滚动到底。
* AI 配置不会影响专注流程。

## 问问霍霍

* AI 未开启时显示引导，不显示误导性的发送入口。
* “去设置”只切换到设置 tab，不触发请求。
* AI 配置不完整时显示配置引导。
* AI 可用时输入框和发送按钮正常显示。
* 请求中禁止重复提交。
* 请求中可以取消。
* 取消后不追加临时上下文，不写入本地记忆。
* 请求失败或超时保留输入，不追加临时上下文。
* 成功后清空输入并显示回复。
* 成功后最多保留最近 3 轮临时上下文。
* 清空临时对话只清 React state，不影响 `companionMemory`。

## 本地记忆

* 成功回复后可以点击“记住这次”。
* 同一次回复不能重复保存。
* 新一次成功回复会重置保存状态。
* “霍霍建议记住”只在命中本地规则时出现。
* 点击“记住”才保存。
* 点击“不用”不保存。
* 取消、失败、超时不显示保存入口。
* 保存内容能在“陪伴”tab 看到。
* 清空陪伴记忆能清除保存内容和状态标签。

## 陪伴分区

* 空状态文案自然，不像报表空数据。
* 最近小记显示正常。
* 查看全部 / 收起正常。
* 清空陪伴记忆需要二次确认。
* 状态标签可以记录，重复选择不会无限堆积。
* 本地小回顾显示正常。
* “去问问”只切换 tab，不触发 AI 请求。

## Live2D 与窗口

* Live2D 模型正常加载。
* idle / ready / focusing / completed / resting 动作自然。
* 找不到 motion group 时安全 fallback，不崩溃。
* 鼠标靠近时视线轻微跟随。
* 鼠标离开后视线自然回正。
* focusing 状态降低视线追踪，减少干扰。
* 透明区域鼠标穿透正常。
* compact / expanded 动态高度正常。
* 隐藏控制入口正常。
* 拖动窗口正常。
* 记住窗口位置正常。
* 托盘、通知、开机启动正常。

## 打包验证

封存前运行：

```bash
npm run check:live2d
npm run build
npm run verify
```

确认：

* `package.json` version 仍为 `0.2.0`。
* `dependencies` 仍为空对象。
* 没有新增依赖。
* Vite chunk 体积 warning 当前不影响构建和打包。
* `dist-release\win-unpacked\Focus Pet.exe` 能正常启动。

## 封存边界

* 不做完整聊天窗口。
* 不保存聊天历史。
* 不做消息流。
* 不做后台主动请求。
* 不自动保存 AI 对话。
* 不改 `companionMemory` 结构。
* 不改 `aiSettings` 结构。
* 不改专注状态机。
* 不改 Live2D 模型。
* 不改窗口透明穿透和动态高度主逻辑。
